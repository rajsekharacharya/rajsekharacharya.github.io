## About this repo

The source of my portfolio, served by GitHub Pages at https://rajsekharacharya.github.io. It is a single hand-written `index.html` with inline CSS and a little vanilla JavaScript. There is no build step.

- Dark and light themes that follow the system setting, with a toggle
- Mobile menu, keyboard focus styles and a skip link
- Respects `prefers-reduced-motion`
- Typography: Bricolage Grotesque and JetBrains Mono
- Open Graph banner and Person structured data for link previews and search

To run it locally, open `index.html` in a browser.
