## About this repo

The source of my portfolio site, served by GitHub Pages. It is a single hand-written `index.html` with inline CSS and a little vanilla JavaScript. There is no build step.

- Dark and light themes that follow the system setting, with a toggle
- Typography: Bricolage Grotesque and JetBrains Mono
- Respects `prefers-reduced-motion`
